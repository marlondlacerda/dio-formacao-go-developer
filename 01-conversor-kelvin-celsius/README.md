# Conversor de Kelvin para Celsius

Desafio prático desenvolvido durante a Formação Go Developer da DIO.

## Descrição

Programa desenvolvido em Go para converter temperaturas da escala Kelvin para Celsius.

## Fórmula

`C = K - 273`

Onde:
- `C`: temperatura em Celsius.
- `K`: temperatura em Kelvin.

## Exemplo de execução

```text
=== Conversor de Kelvin para Celsius ===
Digite a temperatura em Kelvin: 377
377.00 Kelvin equivalem a 104.00 Celsius
```

## Como executar

Com o Go instalado, execute:

```bash
go run main.go
```

## Tecnologia

- Go (Golang)
