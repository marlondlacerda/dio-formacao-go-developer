
# Calculadora em Go

Projeto desenvolvido como parte da formação Go Developer da DIO.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Tratamento de divisão por zero

## Testes

Os testes unitários foram implementados utilizando o pacote `testing` da biblioteca padrão do Go.

## Executar

```bash
go test -v
```

## Tecnologias

- Go
- Testing (biblioteca padrão)
