# Formação Go Developer — DIO

Repositório destinado aos exercícios, desafios práticos e projetos desenvolvidos durante a Formação Go Developer da DIO.

## Objetivo

Consolidar os conhecimentos adquiridos durante a formação, praticando a linguagem Go e registrando minha evolução por meio de projetos versionados.

## Projetos e desafios

| # | Projeto | Descrição |
|---|---|---|
| 01 | [Conversor Kelvin para Celsius](./01-conversor-kelvin-celsius/) | Conversão de temperaturas utilizando operações matemáticas. |
| 03 | [Desafio Ping Pong](./03-desafio-ping-pong/) | Concorrência utilizando goroutines e channels. |
| 04 | [API REST de Clientes](./04-api-rest-clientes/) | API REST para cadastro e gerenciamento de clientes utilizando Gorilla Mux. |
