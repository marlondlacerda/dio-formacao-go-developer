# Desafio Ping Pong

Desafio prático desenvolvido durante a Formação Go Developer da DIO.

## Objetivo

Desenvolver um programa em Go que utilize goroutines e canais para exibir as palavras `ping` e `pong` alternadamente.

## Conceitos praticados

- Goroutines
- Channels (canais)
- Comunicação entre goroutines
- Sincronização de execução
- `sync.WaitGroup`

## Como executar

Na raiz do repositório, execute:

```bash
go run ./03-desafio-ping-pong
```

## Resultado esperado

```text
ping
pong
ping
pong
ping
pong
ping
pong
ping
pong
```
